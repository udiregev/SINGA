  Experimental test page for the Singa app. PDF reading uses pdf.js, with Tesseract.js OCR (including each word's position on the page) for scanned pages. Chord-to-word placement is this page's own nearest-position match using the chord symbols' and lyric words' positions in the original file — for a plain .txt file that's the character column each one starts at; for a PDF or scanned page it's the actual position on the page. It's a best-effort match, not a trained model, so double-check anything that looks off — the title field and the raw text below are there so you can fix or verify it.
