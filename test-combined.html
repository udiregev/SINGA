Combined Song Builder (test)

Upload a recording and a lyrics/chord-sheet file (.txt or .pdf, including scanned PDFs) together. This runs real transcription and chord recognition on the audio, reads the lyrics sheet the same way the File Import Lab does, lines the two up by matching words, and shows one combined result: the sheet's own lyrics and section labels, with chords detected from the actual audio placed over the matching words. Everything here runs for real — nothing is a mockup — but the word-timing alignment between the sheet and the audio is a simple best-effort match, not guaranteed to land on every word.

Combined result

Lyrics and section labels (like "Chorus 2") come from the file you uploaded. Chords come from the audio, either the quick in-browser guess or the AI model, matched to the nearest word by time. The match between the sheet's words and the audio's transcript is done by simple word matching, filling in the gaps in between — the "words matched directly" stat below tells you how much of that is a real anchor versus an estimated guess; treat lines far from any anchor as less trustworthy.

  Experimental test page for the Singa app, combining the File Import Lab and the Audio & Lyrics Analysis Lab into one upload. Transcription runs a Whisper model fully in your browser via WebAssembly (first use downloads roughly 75–150MB). PDF reading uses pdf.js, with Tesseract.js OCR for scanned pages. Chord detection is either an in-browser chroma heuristic or a real deep-learning model (madmom) running on a server you deploy — see the server/ folder in this repo. The alignment between sheet lyrics and sung audio is this test page's own simple nearest-match logic, not a trained model.
