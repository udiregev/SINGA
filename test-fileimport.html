Lyrics File Import Lab

Tests whether Singa can take a real lyrics/chord-sheet file — a .txt or a .pdf — detect what kind of file it is, pull the actual text out of it, and then tell sung lyric lines apart from section labels like "Chorus 2" or "[Bridge]". Runs for real in this browser; the PDF text extraction is a real library (pdf.js), not a mockup.

3 · Detected structure

Same heuristic the main Analysis Lab uses, plus two more categories: a bracketed line like "[Bridge]" always counts as a label; an unbracketed line only counts as one if it's short (≤4 words) and starts with a section keyword (verse, chorus, bridge, intro, outro, solo, etc.), optionally followed by a number ("Chorus 2"). A line made up entirely of chord symbols ("F#m A C#m A") is pulled out as a chord line rather than counted as lyrics. Anything left over gets checked against a list of ~3000 common English words — a line with too few recognizable words (the kind of thing OCR produces when it misreads a chord-diagram grid or tab notation as text) is set aside as noise rather than counted as a lyric. This check only ever matters on an OCR'd page; it's a rough approximation, not a sure thing, so it's worth skimming what got set aside below before trusting the counts.

File-type detection: Singa reads the file's extension/MIME type to decide how to handle it, falling back to sniffing the first bytes when that's missing. Plain text is read directly. PDFs are parsed with pdf.js (the same open-source library Firefox uses to render PDFs), reconstructing line breaks from each text chunk's position on the page. Each page is also checked for whether it's really just a full-page photo/scan with an unreliable (or no) text layer underneath — common for chord sheets downloaded from sheet-music sites or scanned from a printed book. When that's detected, Singa re-reads that page with real OCR (Tesseract.js, running the open-source Tesseract engine entirely in your browser) instead of trusting the page's built-in text, which is usually dramatically more accurate for scanned material.
