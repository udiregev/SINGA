Lyrics File Import Lab

Tests whether Singa can take a real lyrics/chord-sheet file — a .txt or a .pdf — detect what kind of file it is, pull the actual text out of it, and then tell sung lyric lines apart from section labels like "Chorus 2" or "[Bridge]". Runs for real in this browser; the PDF text extraction is a real library (pdf.js), not a mockup.

3 · Detected structure

Same heuristic the main Analysis Lab uses: a bracketed line like "[Bridge]" always counts as a label; an unbracketed line only counts as one if it's short (≤4 words) and starts with a section keyword (verse, chorus, bridge, intro, outro, solo, etc.), optionally followed by a number ("Chorus 2"). Everything else is treated as a sung lyric line.

File-type detection: Singa reads the file's extension/MIME type to decide how to handle it — plain text is read directly, PDFs are parsed with pdf.js (the same open-source library Firefox uses to render PDFs), reconstructing line breaks from each text chunk's position on the page rather than just concatenating words. A scanned/photographed PDF (no real text layer, just an image of a page) will extract little or nothing — that needs OCR, which this lab does not do.
